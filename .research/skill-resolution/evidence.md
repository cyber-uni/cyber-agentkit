# Evidence — How harnesses resolve skills and plugins

All entries dated 2026-10-20. Status values: verified, unverified, contradicts. Confidence: **High** means a vendor
page and a source read or direct experiment agree, or a direct experiment shows it unambiguously. **Medium** means one
of them alone, or a read of a shipped bundle. **Low** means indirect.

Versions run: Claude Code 2.1.304, cursor-agent 2026.09.28-64d2043, codex-cli 0.159.3, GitHub Copilot CLI 1.0.92 (one
session auto-updated to 1.0.100, noted where it matters), OpenCode 1.18.34, Gemini CLI 0.62.0. Experiments ran on Linux
(WSL) with each harness pointed at a throwaway home and a throwaway project, except where a row says it ran from the
real home; no real configuration was changed.
