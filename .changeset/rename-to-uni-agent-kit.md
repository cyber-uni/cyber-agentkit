Rename the package from `@cyberuni/agent-harness` to `uni-agent-kit`. The `agent-harness` command is now `uni-agent-kit`, and the `cyber-agent-harness` agent plugin is now `uni-agent-kit`, so the skill is `/uni-agent-kit:reference`. The package is now described as an agent-harness-agnostic toolkit. Worktree leases written by the old name are no longer recognized as this library's own.
