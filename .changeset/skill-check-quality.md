`skill check` decides four more checks from the files alone, each a warning. TRG-7 fails a description under 12 words or one that uses a phrase that fits any skill, such as "helps with" or "various tasks"; a name-only skill skips it. SHP-12 fails a body with no numbered steps and no `##` sections. SHP-13 fails a skill that bundles scripts and tells the agent to parse a script's output. SHP-14 fails a script that prompts the user with no `--yes` flag documented in the skill's Markdown.
