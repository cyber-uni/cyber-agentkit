The `reference` skill gains a Migrate mode, reached as `/cyber-agentkit:reference migrate` in Claude Code. It runs `reference migrate`, shows every change with the user-tier files called out, and applies them with `--write` only once you approve. Load now tells you that Migrate mode fixes a file a `reference-legacy-format` or `reference-renamed` warning names.
