Reference interfaces that their authors chose to register. Registering is optional. See
[Reference interfaces](/cyber-agentkit/concepts/reference-interfaces/) for what an interface is, and add an
entry with `npx -y cyber-agentkit reference register <id>`. It looks the id up first, then opens a pull
request that adds `registry/interfaces/<id>.md`, or an issue carrying it, once you confirm.
